# YSC_leaf-area-calculator
A software tool that automatically measures plant leaf area from digital images. It performs image preprocessing, contour extraction, and area calculation, supporting various resolutions and formats. Designed to streamline analysis for research and educational use.

## Overview

Yippee Size Calculator is a desktop software that analyzes leaf images
(JPG) and automatically calculates leaf size and related traits. It
provides processed images and an Excel file containing extracted
measurements.

## Required Folder Structure

    project_root/
    ├── test_image_folder/
    │     └── sample.jpg
    └── analysis_image_folder/
          ├── sample1.jpg
          ├── sample2.jpg
          └── ...

-   Only .jpg files are accepted.
-   Folder names may be in any language.
-   Incorrect folder structures cause an error.

## Installation

1.  Download `Yippee Size Calculator (v2.1).zip`
2.  Extract anywhere
3.  Contents:
    -   Yippee Size Calculator.exe
    -   Example images
    -   Manual

## How to Use

### 1. Launch

Double-click the executable.

### 2. Setting Step

-   Select a JPG image for calibration.
-   Confirm the preview.
-   After 100% processing, continue.
-   Choose the best leaf-edge matching image.
-   Review results and choose output file types.

### 3. Analysis Step

-   Select the analysis folder (not images).
-   Confirm path.
-   Wait for processing to finish.

### 4. Completion

Results are saved and opened automatically.

## Re-analysis Options

-   Home: full reset
-   Setting: reset setting step
-   Analysis: reset analysis step only
